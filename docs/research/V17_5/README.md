# V17.5 historical research — superseded orientation policy

V17.5 originally proposed `LANDSCAPE_CANDIDATE` for overly wide tables. **That recommendation is superseded by V17.5.1 / USER-ORIENTATION-001.**

- New tables default to PORTRAIT unless user explicitly specifies otherwise.
- Existing documents must preserve their section orientation unless user requests a change.
- The model may warn about overflow or no safe fit, but may not automatically rotate pages.
- If user explicitly requests landscape, perform authority/locks/section-impact review before any change.
- Read current [V17.5.1 spec](../V17_5_1/V17_5_1_ADMIN_TABLES_USER_CONTROLLED_ORIENTATION_SPEC.md) and [workbook handoff](../V17_5_1/WORKBOOK_PROFILE_HANDOFF.md).

The original 32 V17.5 case labels are retained **for historical migration comparison only**, not as current executable policy.
